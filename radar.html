      ℹ️ Cómo se calcula esto

      El archivo debe tener las hojas POS Q1 y POS Q2 (o cualquier hoja con columnas de fecha ruteada, cobertura y efectividad) — el mismo formato de VALIDACIÓN_2026.xlsx. Se combinan ambas hojas (no se superponen en fechas) y se toma la ventana de las últimas semanas configuradas, contadas desde la fecha ruteada más reciente del archivo.

      Cobertura = la columna "¿Se visitó?" marcada SI. Efectividad se calcula solo sobre las visitas cubiertas. Racha perdida = visitas programadas consecutivas más recientes sin cobertura, para esa tienda. Semanas sin cobertura = tiempo desde la última visita cubierta hasta la fecha más reciente del archivo.

      Filtro de semana: cada semana va de lunes a domingo según la fecha ruteada. Al elegir una semana puntual, los KPIs, alertas y las 3 tablas se recalculan solo con esa semana (la racha y las semanas sin cobertura pierden sentido de tendencia en ese caso — para verlas completas, deja "Todas las semanas"). Filtro de promotor: limita todo a un solo promotor.

      La tabla de motivo de no efectividad muestra el comentario registrado cuando la tienda sí fue visitada pero la visita no se consideró efectiva (columna "Comentario no efectivo" del archivo). Las tiendas que directamente no se visitaron aparecen en la tabla de Tiendas, no aquí.

      Nota de datos: se unifica automáticamente "WILLGERSON PAJITA" / "WILGERSON PAJITA" como un mismo promotor (variante de tipeo detectada en el archivo real). Si aparecen otras variantes de nombre, edítalas en el archivo fuente para que no se cuenten por separado.

      Este radar no reemplaza el archivo semanal detallado — para un Excel con el detalle línea por línea de cada visita perdida, pídeselo a Claude.
